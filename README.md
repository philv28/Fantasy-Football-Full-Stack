# Fantasy Football Lineup Builder

A full-stack fantasy football app for building lineups, checking roster validity, and comparing projected points under lineup constraints.

## V1 Goal
Build a frontend-only prototype with sample player data, roster slots, validation, and projected point totals.

## Planned Stack
- React
- Supabase / Postgres later
- Deployed frontend later

## V1 Features
- Browse players
- Add/remove players from lineup
- Validate roster positions
- Calculate projected points
- Optional salary cap validation
